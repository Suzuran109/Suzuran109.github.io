本教程以 Magellan/MIKE 的合并光谱 e3_2 为例，在 iSpec 图形界面中测量视向速度，用铁线等值宽度求恒星参数，再测量镁和铝相对于铁的丰度。示例光谱的红端分辨率约为 28,000。

一、打开光谱，先把连续谱放到 1 附近

启动 iSpec，选择 Files → Open spectra 打开目标光谱。使用本文示例的 Windows + WSL 配置时，可双击配套的 Start-iSpec.cmd 启动。原始文件只有波长和流量两列，导入前将波长从 Å 换算为 nm，并整理成 waveobs、flux、err 三列。示例没有逐像素误差，err 用 0 占位。若同时打开了多条光谱，检查图例中的 [A] 是否标在目标谱旁。

进入 Operations → Wavelength range reduction，保留 480–675 nm。这一段已经覆盖后面要用的铁、镁、铝线。再进 Operations → Fit continuum… → Splines，滤波顺序选 median+max，两个窗口分别填 0.05 和 1.0 nm。这条谱没有逐像素误差，因此取消按误差加权。拟合线应当沿着谱线之间的上包络走；如果它跟着较深的吸收谷往下弯，先调整窗口再继续。

图 1　连续谱拟合设置。两个窗口的单位都是 nm。

点 Operations → Continuum normalization。现在吸收线附近的连续谱大致在 1，线中心比 1 低。

二、测视向速度，再把谱线移回静止波长

在 Parameters → Determine velocity relative to… → Atomic line mask 中选用 Narval.Sun 掩模，在 −350 到 +350 km/s 内以 0.5 km/s 的步长搜索。iSpec 会将掩模相对光谱逐步移动；吸收线对得最齐的位置，在这张交叉相关图上表现为一个谷。

图 2　读主谷的中心速度，注意保留正负号。

示例光谱的主谷中心为 +3.80 km/s，中心速度的形式拟合误差为 0.04 km/s。点 Cancel 可以退出结果窗，刚算出的速度已经存在当前会话里；在这个结果窗点 OK 会再算一次。回到 Operations → Correct velocity relative to… → Atomic line mask，保留 +3.80，选 Spectra，应用一次校正。

只有在输入波长已做过日心改正的前提下，+3.80 km/s 才能作为该星的日心视向速度。 示例文件没有注明波长参考系，因此可先记录为“输入波长标尺下的视向速度”。上一步将谱线移至恒星静止系，便于和实验室波长逐线匹配。

三、用铁线求恒星参数

如果 Fit lines 弹出 Please, execute a general continuum fit first，先检查连续谱模型。图上的橙色 Fe 标签表示铁线窗口已加载。执行速度校正后，iSpec 会清除先前拟合的连续谱模型。

在已经归一化、做完速度校正的谱上，选 Operations → Fit continuum… → Fixed value，填 1.0。 等左下角出现 Continuum fitted. 再拟合谱线。若还没做过归一化，则先回到第一步。

图 3　为校正后的归一化谱重新指定连续谱高度。

从 Files → Open line regions 打开 iSpec 的 input/regions/42000_GES/spectrum_synth_good_for_params_all_extended.txt。在 Operations → Fit lines 选择 GES 原子线表，允许调整线心，匹配容差取 0.005 nm。线窗规定每条线在哪一段测量，拟合后才有等值宽度（EW）。可以选底部的 Stats → Lines，点选单条线查看。

接着选 Parameters → Determine parameters with equivalent widths。选择 SPECTRUM、MARCS.GES 模型和 Grevesse (2007) 太阳丰度，从 5000 K、log g = 2.5、[M/H] = −0.7、微湍流 1.5 km/s 开始，放开温度、重力和微湍流。计算结束后，检查铁丰度是否还随激发能或谱线强度系统变化，以及中性铁和一次电离铁给出的丰度是否接近。

图 4　上方是两幅铁线平衡图，中间白色列表列出结果，底部输入框仍显示初值。

最后保留 138 条 Fe I、8 条 Fe II，两组丰度中位数相差约 0.01 dex。有效温度为 5061 K，log g = 2.99（cgs），[Fe/H] = −0.48 dex，微湍流为 1.82 km/s。换线窗前可以从 Files → Export fitted lines as… 保存铁线的拟合表。

四、载入完整丰度线窗，读出 [Mg/Fe] 和 [Al/Fe]

通过 Files → Open line regions 加载同一 42000_GES 目录下的丰度线窗文件。

原表有 548 个窗口，其中有 9 条 Mg I 和 2 条 Al I。打开后要再做一次 Fit lines。本次有 451 条谱线成功匹配，其中镁线 7 条、铝线 2 条。然后在 Parameters → Determine abundances with equivalent widths 输入刚得到的恒星参数，模型的 α 增强取 +0.19 dex。结果列表向下滚动，读各元素的 median abundance in [X/Fe]。

元素 匹配条数 [X/Fe] 中位数 线间标准差
Mg I 7 +0.38 dex 0.61 dex
Al I 2 +0.68 dex 0.12 dex

检查逐线丰度。 518.3604 nm 的强线测得 EW 约 239 mÅ，给出 [Mg/Fe] = −1.15 dex；571.1088 nm 的线却给出 +0.17 dex。用高斯轮廓拟合强线时，线翼和连续谱的位置都会影响 EW。报告镁丰度时，应同时给出七条线的中位数和线间标准差。铝的两条线在 669.6023 和 669.8673 nm，分别给出 +0.56 和 +0.79 dex。这里的结果都采用 LTE 假设。

最后在 Files 菜单中用 Save spectrum as… 保存静止系光谱，用 Export fitted lines as… 导出逐线拟合表，并单独记录各元素的丰度中位数、线间标准差和线数。复查某个元素时，可按拟合表中的波长定位到原谱，核对线心和两侧连续谱。
